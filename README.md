# NiHaoUSA

A portal for the Chinese community in the US. First feature: Chinese shows from Mainland China, Taiwan and Hong Kong, curated from official YouTube channels and organized in one place.

- `web/` the website (Next.js). See `web/README.md` for running it, the YouTube ingest, and sign-in setup.
- `design/` the original design mockup and logo.

## Environments

| Branch | Deploys to | Supabase project |
|---|---|---|
| `staging` | staging site (not indexed by search engines) | `nihaousa-dev` |
| `main` | production | a separate production project (not created yet) |
